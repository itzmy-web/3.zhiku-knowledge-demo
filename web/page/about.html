ABOUT · 关于与开源

把文档，变成随问随答的知识库

汇思智藏是一个面向设备手册、企业知识管理与个人资料库的 RAG 知识库。我们关注的不只是"能问答"，而是"答得准、查得到出处"。

🎯 我们解决什么问题

企业的设备说明书、制度文档、合同、培训资料往往又厚又散，员工查一份资料要翻半天。汇思智藏把这些文档统一解析、向量化入库，用自然语言就能问，答案附带引用出处，减少重复答疑、降低培训成本。

对个人用户，它是一个可私有化沉淀的学习笔记 / 论文 / 电子书问答助手，数据完全掌握在自己手里。

🧠 技术栈

核心是一条"先查资料、再回答"的检索增强（RAG）流水线：

多格式解析（PDF/Word/TXT/MD/图片） 自动切分 + 向量化 稠密 + 稀疏 + HyDE 三路召回 RRF 融合排序 交叉编码器精排 断崖截断 SSE 流式输出 Milvus 向量库 MinIO 对象存储 MongoDB 元数据 Docker 一键部署

⚖ 与同类产品的差异

维度汇思智藏通用聊天 / 笔记工具
答案依据严格基于你的文档，带引用溯源可能凭通用知识编造
检索能力三路召回 + RRF 融合 + 精排多为单一向量检索
数据归属私有化部署，数据不出服务器常驻第三方云端
部署方式Docker 一键自托管，开源多为 SaaS 订阅
场景侧重设备手册 / 企业知识库 / 个人资料库通用

注：以上为产品设计目标与差异化定位；具体能力边界以实际版本为准。与 AnythingLLM / OpenWebUI / PrivateGPT 等开源方案相比，汇思智藏强调"多路召回 + 重排流水线"的检索质量与面向手册 / 企业场景的开箱体验。
