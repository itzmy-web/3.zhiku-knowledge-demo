常见问题

关于安全、费用、能力的直白回答。

私有化部署：文档、向量库、会话历史全部留在你自己的服务器（Milvus / MinIO / MongoDB），不经过第三方。
云端演示站：为公开共享环境，请勿上传任何真实或涉密资料；演示站仅用于体验交互，不保证数据隔离与持久化。
演示站：永久免费体验。
私有化部署：提供免费自托管方案；具体开源协议、仓库地址与商用授权请以项目主页 / 文档为准（本页不代行法律声明）。
支持 PDF / Word / TXT / MD / 图片。小文档可秒级入库；但大文件、扫描版 PDF（需 OCR）按体积通常需要数十秒到数分钟，我们不再用「3 秒」做笼统承诺——以实际文件大小为准。
设计目标是：答案严格基于你的文档并标注引用来源；当知识库检索不到相关内容时，应明确提示「文档中未找到相关信息」，而非凭空生成。实际效果取决于文档质量与检索配置。
头部知识库产品的检索速度通常在 0.3–1.2 秒区间。汇思智藏本地部署的性能主要取决于硬件，Milvus 向量库建议 ≥16GB 内存，小机器易 OOM。具体部署建议见部署文档。

安全与合规

企业关心的，我们先讲清楚。

🔒 数据自持
私有化部署时数据完全留在用户侧，不上传第三方大模型 API（可配置完全离线）。
🛡 权限与隔离
规划支持管理员 / 编辑 / 查看三级角色与知识库级访问控制；多租户检索强制带租户 ID 过滤（企业版能力）。
📜 隐私与审计
提供隐私说明页面；计划支持访问 / 修改审计日志，满足企业合规与追溯需求。
